
2. 安装核心依赖:
   ```bash
   npm install react@^18.3.0 react-dom@^18.3.0
   ```

3. 安装开发依赖:
   ```bash
   npm install -D vite@^5.0.0 @vitejs/plugin-react@^4.0.0 typescript@^5.0.0 @types/react@^18.3.0 @types/react-dom@^18.3.0 @types/chrome@latest tailwindcss@^3.4.0 postcss@^8.0.0 autoprefixer@^10.0.0 @niccolopaganini/vite-plugin-web-extension@latest
   ```
   注意: 使用 vite-plugin-web-extension 插件来处理 Chrome Extension 的构建。如果 @niccolopaganini/vite-plugin-web-extension 不可用，尝试 @niccolopaganini/vite-web-extension 或 vite-plugin-web-extension 或 @niccolopaganini/vite-plugin-chrome-extension。找到一个可用的 Vite Chrome Extension 插件即可。如果没有合适的插件，使用 @crxjs/vite-plugin 作为替代。

4. 创建 tsconfig.json:
   ```json
   {
     "compilerOptions": {
       "target": "ES2020",
       "useDefineForClassFields": true,
       "lib": ["ES2020", "DOM", "DOM.Iterable"],
       "module": "ESNext",
       "skipLibCheck": true,
       "moduleResolution": "bundler",
       "allowImportingTsExtensions": true,
       "resolveJsonModule": true,
       "isolatedModules": true,
       "noEmit": true,
       "jsx": "react-jsx",
       "strict": true,
       "noUnusedLocals": true,
       "noUnusedParameters": true,
       "noFallthroughCasesInSwitch": true,
       "forceConsistentCasingInFileNames": true
     },
     "include": ["src"]
   }
   ```

5. 创建 tailwind.config.js:
   ```js
   /** @type {import('tailwindcss').Config} */
   export default {
     content: ['./src/**/*.{js,ts,jsx,tsx,html}'],
     theme: {
       extend: {},
     },
     plugins: [],
   }
   ```

6. 创建 postcss.config.js:
   ```js
   export default {
     plugins: {
       tailwindcss: {},
       autoprefixer: {},
     },
   }
   ```

7. 创建 src/styles/global.css:
   ```css
   @tailwind base;
   @tailwind components;
   @tailwind utilities;
   ```

8. 创建 vite.config.ts — 这是关键文件，配置取决于使用的 Chrome Extension 插件。以 @crxjs/vite-plugin 为例:
   ```ts
   import { defineConfig } from 'vite';
   import react from '@vitejs/plugin-react';
   import { crx } from '@crxjs/vite-plugin';
   import manifest from './src/manifest.json';

   export default defineConfig({
     plugins: [
       react(),
       crx({ manifest }),
     ],
     build: {
       outDir: 'dist',
       emptyDirFirst: true,
     },
   });
   ```
   如果使用不同的插件，按该插件文档调整配置。核心要求: manifest.json 作为输入，dist/ 作为输出目录。

9. 在 package.json 中添加 scripts:
   ```json
   {
     "scripts": {
       "dev": "vite",
       "build": "tsc && vite build",
       "preview": "vite preview"
     }
   }
   ```

注意: 如果 tsc 在 build 中报错导致无法构建，可以将 build 脚本改为 "vite build" (不做类型检查)，单独添加 "typecheck": "tsc --noEmit" 脚本。优先保证构建通过。

1. 创建 src/manifest.json:
   ```json
   {
     "manifest_version": 3,
     "name": "注意力队列 - Attention Queue",
     "version": "0.1.0",
     "description": "Chrome 标签组的搜索层 + 持久化层",
     "permissions": [
       "storage",
       "tabGroups",
       "tabs"
     ],
     "background": {
       "service_worker": "src/background/index.ts"
     },
     "icons": {
       "16": "icons/icon16.png",
       "48": "icons/icon48.png",
       "128": "icons/icon128.png"
     }
   }
   ```
   注意: background.service_worker 的路径取决于使用的 Vite 插件。
   - 如果使用 @crxjs/vite-plugin: 路径写 "src/background/index.ts"（插件会自动处理编译）
   - 如果使用其他插件: 路径可能需要写编译后的路径如 "background.js"
   根据 Task 1 实际安装的插件文档调整。

2. 创建 src/background/index.ts — 最小 Service Worker:
   ```typescript
   // Service Worker for 注意力队列 Chrome Extension
   // Phase 1: 基础骨架，验证扩展可加载

   console.log('[Attention Queue] Service Worker registered');

   chrome.runtime.onInstalled.addListener((details) => {
     console.log('[Attention Queue] Extension installed:', details.reason);
   });
   ```

3. 创建扩展图标 — 使用简单的 placeholder 图标。生成 16x16、48x48、128x128 的 PNG 文件:
   - 方法1: 使用 canvas 生成简单的彩色方块图标（写一个 Node.js 脚本）
   - 方法2: 创建简单的 SVG 然后转换
   - 方法3 (推荐): 使用 npm 包如 `pngjs` 或直接用代码生成最小有效 PNG

   如果无法程序化生成 PNG，创建一个占位 scripts/generate-icons.js:
   ```javascript
   // 生成最小有效 PNG 文件作为 placeholder 图标
   const fs = require('fs');
   const path = require('path');

   // Minimal 1x1 PNG (will be scaled by Chrome)
   // 实际可以生成更大的带颜色的图标
   const sizes = [16, 48, 128];
   const iconsDir = path.join(__dirname, '..', 'public', 'icons');
   fs.mkdirSync(iconsDir, { recursive: true });

   // 生成简单的纯色 PNG placeholder
   // ... (使用 Buffer 创建有效 PNG 二进制数据)
   ```

   最简单的方案: 在 public/icons/ 下放置有效的 PNG 文件。可以使用 base64 编码的最小有效 PNG 写入文件。
