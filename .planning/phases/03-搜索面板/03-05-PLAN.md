```typescript
// ============================================

// ============================================

chrome.commands.onCommand.addListener(async (command) => {
  if (command === "toggle-search") {
    console.log('[Search Panel] Toggle command received');
    try {
      const [tab] = await chrome.tabs.query({ active: true, currentWindow: true });
      if (tab.id) {
        await chrome.tabs.sendMessage(tab.id, { type: 'TOGGLE_SEARCH_PANEL' });
        console.log('[Search Panel] Message sent to tab:', tab.id);
      }
    } catch (error) {
      console.error('[Search Panel] Failed to send message:', error);
    }
  }
});
```

**为什么这样做：**
- chrome.commands API 只能在 background/service worker 中使用
- 使用 chrome.tabs.sendMessage 将命令转发到当前活动标签页的 content script
- 添加错误处理和日志便于调试

修改 src/content/index.tsx，移除错误的 chrome.commands 调用，改用消息监听：

1. **删除** useEffect 中的 chrome.commands.onCommand.addListener 代码块（第 9-14 行）

2. **替换为** chrome.runtime.onMessage 监听器：

```typescript
useEffect(() => {
  // 监听来自 background 的消息
  const messageListener = (
    message: { type: string },
    sender: chrome.runtime.MessageSender,
    sendResponse: (response?: any) => void
  ) => {
    if (message.type === 'TOGGLE_SEARCH_PANEL') {
      setIsOpen((prev) => !prev);
      sendResponse({ success: true });
    }
  };

  chrome.runtime.onMessage.addListener(messageListener);

  // 监听 Esc 键关闭面板
  const handleKeyDown = (e: KeyboardEvent) => {
    if (e.key === "Escape" && isOpen) {
      setIsOpen(false);
    }
  };

  document.addEventListener("keydown", handleKeyDown);

  return () => {
    chrome.runtime.onMessage.removeListener(messageListener);
    document.removeEventListener("keydown", handleKeyDown);
  };
}, [isOpen]);
```

**为什么这样做：**
- chrome.commands 在 content script 中不可用，必须通过消息机制
- 使用 chrome.runtime.onMessage 接收来自 background 的消息
- 保持 Esc 键监听逻辑不变
- 正确清理监听器避免内存泄漏
