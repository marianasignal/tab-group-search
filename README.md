# 标签组检索插件

**[在 Chrome 应用商店安装](https://chromewebstore.google.com/detail/fdkkfaokcpdgclionojiliblbacphljl)** · 已发布版本：1.0.3

Chrome 浏览器扩展，将网页管理从"标签页状态"转变为"数据库思维"。通过增删查操作管理网页，以注意力为核心，快速找到需要的内容，同时释放浏览器内存。

## 核心功能

| 功能 | 说明 |
|------|------|
| **标签组同步** | 自动将 Chrome 标签组数据持久化到本地存储 |
| **快速搜索** | 按 `Ctrl+Space` 打开搜索面板，3秒内找到任意网页 |
| **分组筛选** | 支持按标签组筛选，快速定位目标内容 |
| **模糊匹配** | 按网页标题和网址进行模糊搜索 |

## 核心价值

> **快速检索** — 用户能在 3 秒内通过关键词或分类找到并打开任何已保存的网页

## 技术栈

- **构建工具**: Vite 5.x
- **前端框架**: React 18.3 + TypeScript
- **样式方案**: Tailwind CSS
- **搜索库**: Fuse.js（模糊搜索）
- **存储方案**: chrome.storage.local

## 安装

### 从 Chrome 应用商店安装

打开[插件的商店页面](https://chromewebstore.google.com/detail/fdkkfaokcpdgclionojiliblbacphljl)，点击“添加至 Chrome”，按浏览器提示确认安装。

### 从源码安装（开发者）

1. 构建项目: `npm run build`
2. 打开 Chrome 扩展管理页面: `chrome://extensions/`
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `dist` 文件夹

## 使用

### 初始化：保存标签组

1. 在 Chrome 中打开所有想要长期保留的标签组，确保目标网页已加入标签组。未分组的标签页不会被保存。
2. 最好等所有目标标签页加载完毕，确保同步时能读取完整的标题和网址。
3. 按 `Ctrl+Space`（Ctrl + 空格），或点击扩展图标后点击“打开搜索面板”，再点击“同步”并确认。
4. 等待同步完成，检查面板中能否找到需要的分组和网页。确认保存后，就可以关闭原标签页或整个标签组，之后仍能通过插件找到它们。

**同步会覆盖历史记录**：它会用当前 Chrome 所有窗口中已打开的标签组重建记录，清除不在其中的旧记录。已关闭的标签组不会参与这次同步；如果当前没有打开任何标签组，同步会清空记录。日常检索无需再次点击“同步”，只有打算用当前打开的标签组替换历史记录时才使用它。

### 日常使用：查找并打开单个网页

1. 按 `Ctrl+Space`，或点击扩展图标后点击“打开搜索面板”。
2. 点击顶部分组名称，查看该组已保存的网页；也可以在搜索框输入关键词，按**网页标题或网址**模糊搜索。先选分组再搜索，可缩小搜索范围；点击“全部”可取消分组筛选。
3. 点击需要的结果，或在搜索框中按 `↑` / `↓` 选择、按 `Enter` 打开。插件会在新标签页中打开该网页。
4. 按 `Esc` 或点击面板外的遮罩关闭面板。

### 使用特点与注意事项

- **保存一次，按需打开单页**：标签组关闭后，仍可从已保存的记录中检索并打开其中一个网页，无需重开整个标签组。
- **保存网页入口**：记录包括标题、网址和分组信息，不包含网页正文的离线副本。重新打开时会访问原网站。
- **仅在本机保存**：记录保存在当前 Chrome 配置文件中，不会跨设备或跨配置文件同步。这里的“同步”指将标签组记录保存到本地。
- **快捷键可调整**：如果 `Ctrl+Space` 与输入法或其他软件冲突，可在 `chrome://extensions/shortcuts` 中为本扩展修改快捷键。

面板仅在用户触发快捷键或点击扩展弹窗中的按钮时加载，不申请所有网站的持久访问权限。在 Chrome 内置页面、Chrome 应用商店等受限页面上，会打开扩展自带的搜索页；按 Esc 或点击搜索结果可关闭该页。

## 设计原则

- **无状态设计**: 所有状态存储在 chrome.storage.local，不使用全局变量
- **事件驱动**: 每个 listener 独立工作，Service Worker 可能随时重启
- **本地保存**: 自动同步保留标签组中已记录的网页；关闭标签页不会自动删除记录，手动同步会重建记录
