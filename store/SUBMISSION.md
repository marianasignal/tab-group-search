## 简短描述

按标题或网址搜索 Chrome 标签组中的网页，支持分组筛选与本地保存。

## 详细描述

标签组检索插件帮助你从 Chrome 标签组中找到需要的网页。

主要功能：

- 使用 Ctrl+Space 或扩展按钮打开搜索面板。
- 按网页标题或网址进行模糊搜索。
- 点击标签组名称缩小搜索范围。
- 使用方向键选择结果，按 Enter 打开网页，按 Esc 关闭面板。
- 在浏览器本地保存已记录的标签组网页，关闭网页后仍可搜索已保存记录。
- 手动同步当前打开的标签组。

关于数据：

标签组记录保存在当前浏览器的本地存储中，扩展不会将它们上传到开发者服务器。无需创建扩展账号，也没有广告或远程行为统计。

请注意：

- 手动同步会在确认后，用当前打开的标签组覆盖历史记录。
- Ctrl+Space 可能与输入法或其他软件冲突，可在 chrome://extensions/shortcuts 中调整。
- Chrome 内置页面等受限制页面无法显示内容脚本。当前版本会在部分受限页面显示提示并打开 Google 网页，再尝试显示面板。
- 本扩展不会自动关闭标签页或释放其内存，不提供拼音转写或云端同步。

## 单一用途

在当前浏览器中保存并检索 Chrome 标签组中的网页，让用户按标题、网址或分组找到并重新打开网页。

## 权限说明

| 后台字段 | 可填写的用途说明 |
| --- | --- |
| storage | 将标签组网页记录和同步时间保存在 chrome.storage.local，使用户在关闭网页后仍可检索已经记录的网页。 |
| tabGroups | 读取用户现有标签组的名称和颜色，并监听创建、修改等事件以更新本地记录。 |
| tabs | 读取标签页的网址、标题和 groupId，建立可搜索的本地标签组记录。 |
| activeTab | 用户触发扩展快捷键或按钮时，临时访问当前标签页，支持在尚未加载面板脚本的普通网页上启动面板。 |
| scripting | 在用户触发快捷键且目标页未加载内容脚本时，注入扩展包内的 JavaScript 和 CSS。脚本路径来自扩展自己的 manifest。 |
| notifications | 告知用户当前页面受 Chrome 限制、无法展示搜索面板。 |
| HTTP/HTTPS 网站访问 | 在用户浏览的普通网页上提供统一的搜索面板；脚本不采集网页正文、表单或密码，不使用外部服务器处理页面内容。 |

`commands` 是清单配置项，不作为权限申请。全部可执行脚本打包在扩展中；远程代码字段填写“不使用远程代码”。

## 隐私披露核对

扩展会在设备本地处理网址和标题等与浏览活动有关的数据，因此提供隐私政策。不要将“未向服务器上传”表述为“不读取任何用户数据”。

后台各数据类型复选框必须根据提交时显示的定义填写：

- 若“收集”指从用户设备传出到开发者或第三方服务器，本版本不进行此类收集。
- 若字段涵盖本地访问或处理，应披露网址、标题等网页浏览相关数据。
- 本版本不出售数据，不向无关用途转移数据，不将数据用于信用评估或贷款业务。账号持有人在核对实现和政策后再确认相关声明。

特殊页面打开 Google 的行为和本机调试日志已在隐私政策披露。请勿在测试截图、公开 Issues 或开发者反馈中附带真实浏览记录。

## 审核员测试步骤

1. 安装扩展，无需注册扩展账号或输入测试凭据。
2. 打开几个公开网页，将它们加入两个有不同名称的 Chrome 标签组。
3. 在普通 HTTPS 网页上按 Ctrl+Space，或点击扩展按钮。
4. 搜索网页标题或网址中的一段文字，检查结果变化。
5. 点击分组名称，检查结果只来自对应分组。
6. 用方向键选择结果并按 Enter，检查网页在新标签页打开。
7. 关闭一个已记录的标签页，再次打开搜索面板，检查记录仍可检索。
8. 在演示数据环境点击“同步”，确认提示后检查记录与当前打开的标签组一致。
9. 在 Chrome 内置页面触发快捷键，检查通知及普通网页上的打开流程。
10. 在扩展更新前已打开的普通网页上触发快捷键，检查脚本补充注入流程。

第 8 步会覆盖本扩展保存的历史数据，应在演示配置文件中测试。
